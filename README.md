# PROG2004 Assessment 1 - Clinic Appointment System

Jiarui Zhang (25259638)

A Java console application for a small health clinic where a patient books a
same day appointment with a general practitioner, a specialist, a nurse or a
dietitian.

## How to run

    cd A1-25259638
    javac -d out src/*.java
    java -cp out AssignmentOne

The project is under construction; the design notes will be added when the
classes are complete.
