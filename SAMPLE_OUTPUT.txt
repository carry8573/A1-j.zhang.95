 PART 5 - WHEN ARE TWO HEALTH PROFESSIONALS THE SAME?
================================================================

The clinic stores Dr Alice Nguyen (ID 1001) and a second object was
created with the same ID but a different spelling of the name and a
different room. The Java way to compare objects is equals(), so:

   alice.equals(aliceCopy)                 : true
   alice.hashCode() == aliceCopy.hashCode(): true

The ID is the clinic's unique key, so equals() and hashCode() compare
the ID only. That is also why an appointment can treat two bookings for
the same professional at the same time as the same booking.

 PART 6 - BOOKING ERROR CASES
================================================================

The manager refuses a booking it cannot make, and explains why:

   [same professional, same time]
   BOOKING REJECTED: Dr Alice Nguyen (ID 1001) is already booked at 09:00.

   [a time that is not one of the clinic's slots]
   BOOKING REJECTED: 09:15 is not a clinic slot. The clinic runs 08:00-16:00, 30 minute slots (16 slots per professional).

   [a professional who is not working today]
   BOOKING REJECTED: Dr Priya Raman (General Practitioner, ID 1003) does not work on Monday; the roster is Tuesday, Thursday, Saturday, Sunday.

   [no appointment details at all]
   BOOKING REJECTED: no appointment details were supplied.

An appointment that is missing information cannot even be
created, so an invalid appointment can never reach the manager:
   IllegalArgumentException: An appointment must have a patient.
   IllegalArgumentException: A mobile number must contain digits only, but was "0412-ABC".
